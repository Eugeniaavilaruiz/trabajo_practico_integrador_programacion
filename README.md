# Sistema de Control de Inventario

Trabajo Práctico Integrador de **Programación 1** — Universidad Tecnológica Nacional, Tecnicatura Universitaria en Programación.

**Autora:** Eugenia Avila Ruiz
**Comisión:** A26 C1-02

## Descripción

Programa en Python para gestionar el inventario de una ferretería. Permite cargar herramientas, ver el inventario, consultar el stock, ver las herramientas agotadas, dar de alta productos nuevos y registrar ventas e ingresos. Los datos se guardan en una lista de diccionarios, cada opción del menú es una función y los errores se manejan con `try`/`except` y `raise`, sin que el programa se interrumpa.

## Cómo ejecutarlo

Requiere Python 3.12 o superior.

    python codigo_fuente_trabajo_integrador_programacion.py
